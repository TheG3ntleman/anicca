# 3:09 PM, Tree Structure and Free-form Editor Widget
Entries will have a tree-like structure with a configurable maximum nesting depth, starting from a root narrative/base node containing free-form text. Typing `@` followed by a selector opens the command options and creates a corresponding box within that text; boxes with free-form text can themselves contain further boxes. Nodes without free-form text, such as attachments, are always leaves, and text-bearing nodes without embedded boxes are leaves as well. The editor widget manages box boundaries, endpoints, fields, and nested structures internally, maintaining both a serialized raw string with structural markers and its corresponding parsed tree; the user only starts boxes and edits their contents, without manually writing closing syntax. Backspace on the box itself reverses its creation and displays the original `@selector` text so the selector can be edited again, while Backspace inside the box edits its content normally. Reversing a populated box must preserve its contents rather than silently discard them.
